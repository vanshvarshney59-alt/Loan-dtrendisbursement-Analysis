# D17 Synthetic Data Files

All records are synthetic, generated with seed 42. They are not real bank or customer records.

- `loan_transactions_sample.csv`: deterministic 12,000-event synthetic input dataset.
- `loan_transactions_clean.csv`: validated clean dataset; 12,000 rows passed validation.
- `monthly_summary.csv`: monthly disbursement aggregates.
- `loan_type_summary.csv`: loan type aggregates.
- `branch_summary.csv`: branch aggregates.
- `channel_summary.csv`: channel aggregates.

The summary files use successful disbursement events as defined in the project report. They are descriptive outputs from this synthetic sample.
